# AIDX推進ポータル

AIDX(AI活用による組織変革)を推進する人のための実践ナレッジサイト。

**サイト**: https://fladdict.github.io/ai-dx-portal/

> AIDXはツール導入ではなく組織の再設計である。モデルとツールは陳腐化するが、構造化された業務・データ・人の検証能力は複利で効く。

## 構成

- **原理編** — AIDXの定義、時間軸の考え方、反脆弱性、複利の法則、負債とスロップの分類学
- **AI-Ready編** — 5つの資産による現在地診断(25問チェックリスト)と成熟度モデル
- **組織・人材編** — 業務分解と再配置、検証者へのシフト、育成パイプライン、推進体制とガバナンス、取締役会の監督義務
- **ロードマップ編** — 最初の90日、投資判断の5択、1年プランと3年シナリオ、経営計画への翻訳、リターン構造、撤退プレイブック
- **部門別ガイド** — 10部門それぞれの業務分解マップと最初の90日
- **業務パターン集 / アンチパターン集 / 用語集**

## 編集方法

- コンテンツはAIが生成し、人間が検証しています
- 事実には出典(`sources/` の一次情報)を紐付け、出典タグのない推奨・解釈は編集部の見解です
- 統計・ツール情報は陳腐化前提の「回転在庫」として定期的に入れ替えます

## ビルド

```bash
npm install
npm run dev      # 開発サーバー
npm run build    # ビルド
```
